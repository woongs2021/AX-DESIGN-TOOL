# Phase 1 — Online Studio

목표: Archive에 쌓인 35개 디자인 작업물을 테마로 골라, 인스타그램·페이스북·유튜브 커버·쇼츠 같은 **온라인 마케팅 브랜드 에셋**을 만들고 PNG로 다운로드하는 툴을 만든다.

참조 결정: `D-01`, `D-03`, `D-04`, `D-11`, `D-12`, `D-14` / 기반: [Phase 0 Archive Foundation](phase-0-foundation.md)

> 상태: **구현됨** (`src/views/studio.ts`, `src/shared/studio.ts`, `src/shared/studio-shapes.ts`, `src/shared/studio-presets.ts`). 코드 영역은 HTML + CSS 조각이다. 아래 1-1부터 1-14는 만든 순서다.

## 범위

- 입력: 빌드된 `index.json`의 캡처 35건과 각 테마 이미지. Markdown은 읽지 않는다. (`D-01`)
- 출력: 선택한 SNS 규격 크기의 PNG. 브라우저에서 바로 다운로드한다.
- 서버·LLM 호출 없음. 합성은 브라우저 안에서 일어난다. (`D-11`)
- 생성 PNG는 vault와 배포 번들에 저장하지 않는다. 카드 상태는 세션 메모리, 초기화 기준과 추가 이미지는 그 브라우저에만 둔다.

### 1-1 정보 구조

계획: Intake, Design System, Stats 탭을 없애고 마케팅 카드를 만드는 화면 하나로 모은다. 예전 주소는 새 화면으로 이어진다.

구현: 네비는 Graphic Library / Online Studio / History다. 공개 사이트는 [Graphic Library](https://woongs2021.github.io/AX-DESIGN-TOOL/#/), [Online Studio](https://woongs2021.github.io/AX-DESIGN-TOOL/#/studio), [History](https://woongs2021.github.io/AX-DESIGN-TOOL/#/history)다. `#/intake`, `#/design-system`, `#/stats`는 `#/studio`로 이동한다. 상세 화면의 `이 테마로 만들기`는 `#/studio?theme=<slug>`로 그 작업물을 고른 채 연다. `npm run ingest`와 `npm run design-system`은 탭과 별개인 로컬 CLI로 남긴다.

### 1-2 스튜디오의 뼈대

계획: 왼쪽에서 카드를 조절하고 오른쪽에서 결과를 본다. SNS 규격으로 크기를 고르고, 글자·이미지·색을 넣은 뒤 PNG로 받는다. 같은 상태를 코드로도 볼 수 있다.

```text
┌──────────────────────────── AX DESIGN STUDIO ─────────────────────────────┐
│ Control panel (좌)          ┃ Preview (우)                               │
│ ┌ [Design] [Code] 탭 ─────┐ ┃                                            │
│ │ 카드 크기 프리셋         │ ┃      ┌──────────────────┐                  │
│ │ 도형 / 선 / 펜           │ ┃      │   카드 프리뷰     │                  │
│ │ 너비 / 높이 (바 + 수치)  │ ┃      │   (실제 비율)     │                  │
│ │ 타이틀 / 본문 + 폰트 크기│ ┃      └──────────────────┘                  │
│ │ 폰트                     │ ┃                                            │
│ │ 아카이브 테마 (35개)     │ ┃  1080 × 1080 · Instagram Feed              │
│ │ 이미지 크기              │ ┃                        [PNG 다운로드]      │
│ │ 컬러 / radius            │ ┃                                            │
│ └─────────────────────────┘ ┃                                            │
└────────────── 드래그 분할 바 ┃────────────────────────────────────────────┘
```

도형 / 선 / 펜 줄은 1-12에서 카드 크기 프리셋 아래에 들어갔다. 프리뷰 아래의 줌·Fit·되돌리기는 1-4, 디바이스 뷰는 1-5다.

구현:

- 768px 이상에서는 컨트롤 패널(기본 360px)과 프리뷰 사이에 분할 바가 있다. 드래그하거나 좌우 화살표로 너비를 바꾼다. 767px 이하는 프리뷰가 위, 컨트롤이 아래다.
- 컨트롤은 Design / Code 두 탭이고 같은 `StudioState`를 쓴다.
- 카드 크기는 8개 프리셋이다. 처음 값은 Instagram Feed 1080×1080. 너비·높이는 100~4000px로 직접 바꿀 수 있다.

| id | 이름 | 크기(px) |
|---|---|---|
| `ig-feed-square` | Instagram Feed (기본값) | 1080 × 1080 |
| `ig-feed-portrait` | Instagram Feed Portrait | 1080 × 1350 |
| `ig-story` | Instagram Story / Reels | 1080 × 1920 |
| `fb-feed` | Facebook Feed | 1200 × 630 |
| `fb-cover` | Facebook Cover | 1640 × 624 |
| `yt-thumbnail` | YouTube Thumbnail | 1280 × 720 |
| `yt-banner` | YouTube Channel Cover | 2560 × 1440 |
| `yt-shorts` | YouTube Shorts | 1080 × 1920 |

- 타이틀과 본문, 폰트 크기, 아카이브 테마, 이미지 크기와 위치, 카드 컬러, 카드 radius(0~120px, 기본 28px)를 조절한다.
- 프리뷰와 PNG는 같은 캔버스 함수로 그린다. 파일명은 `ax-studio-<너비>x<높이>-<theme-slug>.png`. radius 바깥은 투명하다.
- 코드 탭은 HTML + CSS 조각을 sandbox iframe에서만 렌더한다. 스크립트는 실행하지 않는다. `현재 디자인을 코드로 복사`는 디자인 상태를 같은 형식의 코드로 낸다. 비어 있으면 디자인 렌더를 쓴다.

### 1-3 폰트, 초기화, 첫 화면

계획: 타이틀과 본문이 다른 폰트를 쓰고, 카드를 처음 값으로 되돌릴 수 있다. 라이브러리는 고르는 화면으로 단순하게 둔다.

구현: 타이틀·본문 폰트를 따로 고른다. 기본은 Roboto, Pretendard, Montserrat이고 `fonts/`에 파일을 넣은 뒤 다시 빌드하면 목록에 붙는다. 첫 방문 화면 모드는 다크다. Archive는 Graphic Library가 되고, 검색창과 필터 없이 All / Pin만 남는다. 타이틀 시작 문구는 이후 `Hello`, 본문은 헤르메스 문장으로 바뀌어 1-11의 내장 기준에 들어 있다.

### 1-4 크기 연동과 프리뷰 조작

계획: 카드 비율을 유지한 채 키우고, 실수한 조절을 되돌리며, 프리뷰를 확대한다.

구현: `너비·높이 함께`는 비율을 유지한 채 프레임과 이미지를 같이 바꾸고 폰트 크기와 글자 위치는 유지한다. `−` / `+`는 맞춤 크기 기준 50~300%다. `Fit`은 사방 10px 여백의 100%로 되돌린다. 이전 동작·원래대로는 슬라이더 한 번, 입력칸 한 번, 드래그 한 번을 한 단계로 기록하고 최대 40단계다. 드래그하는 동안만 잡은 영역에 테두리가 보이고 PNG에는 들어가지 않는다.

### 1-5 화면 크기와 그 자리 수정

계획: 폰·태블릿·데스크탑에서 같은 스튜디오를 보고, 글자와 이미지를 프리뷰에서 바로 고친다.

구현: 헤더 아래 디바이스 바로 모바일 390px, 태블릿 820px, 데스크탑 전체 폭을 고른다. 창이 좁으면 가능한 단계로 내려갔다가 넓어지면 돌아온다. 모바일 레이아웃은 프레임 폭 기준이다. 이미지는 핀치와 상하좌우 핸들로 크기를 조절한다. 타이틀·본문을 두 번 누르면 그 자리에서 고친다.

### 1-6 선택과 정렬

계획: 카드 위의 객체를 골라 함께 옮기고 맞춘다.

구현: 클릭은 그 객체만, Shift+클릭은 더하거나 뺀다. 선택된 것을 끌면 함께 움직이고, 하나가 카드 가장자리에 닿으면 같이 멈춘다. 한 개 이상이면 프리뷰 위에 정렬 바가 뜬다. 여섯 방향은 카드에 맞추고, 세 개 이상이면 가로·세로 간격을 같게 맞춘다. Option/Alt를 누른 채 끌면 복제된다. 이전 동작은 Cmd/Ctrl+Z, 원래대로는 Cmd+Shift+Z · Ctrl+Y · Ctrl+Shift+Z다.

### 1-7 레이어와 이미지

계획: 글자와 이미지를 여러 장 쌓고, 이미지를 잘라 쓰며, 테마 밖 이미지도 넣는다.

구현: 기본 순서는 이미지, 본문, 타이틀이다. 같은 종류를 여러 개 둘 수 있다. 오른쪽 클릭 또는 길게 눌러 복사, 붙여넣기, 맨 위, 맨 아래, 크롭, 삭제를 연다. 타이틀·본문·이미지는 종류마다 마지막 하나는 지울 수 없다. 크롭은 원본을 지우지 않고 보이는 영역만 저장한다. 테마 썸네일을 프리뷰에 놓으면 그 자리에 새 이미지 레이어가 생긴다. `+`로 넣은 이미지는 그 브라우저에만 저장되고 ×로 지운다.

### 1-8 글자 스타일과 색 찍기

계획: 글자의 굵기·기울기·밑줄·정렬을 바꾸고, 화면의 색을 집어 쓴다.

구현: 굵기는 Light 300부터 Bold 700까지, 볼드·이탤릭·밑줄, 왼쪽·가운데·오른쪽 정렬이 레이어 전체에 적용된다. 방향키는 0.5px, Shift+방향키는 10px이다. Cmd/Ctrl+C·V로 레이어를 복사해 붙인다. Delete는 선택한 레이어를 지운다. I는 스포이드다. 글자를 선택했으면 그 글자색이, 아니면 카드 배경색이 바뀐다.

### 1-9 프리셋과 초기화 기준

계획: 규격마다 자주 쓰는 배치를 기억하고, 크기 조절을 클릭으로도 한다.

구현: 프리셋은 2열 그리드다. 크기 조절바 오른쪽 −/+는 2px, Shift와 함께면 10px이다. `초기화로 세팅`은 지금 레이아웃을 그 프리셋의 기준으로 브라우저에 저장한다. 그 프리셋을 다시 누르면 그 배치가 불러와진다. 설정 메뉴의 리셋은 저장한 기준을 지운다.

### 1-10 테마 확장

계획: 그래픽 라이브러리와 스튜디오가 같은 작업물을 더 많이, 더 선명하게 쓴다.

구현: 17–20번으로 20점, 21–30번으로 30점, 31–35번으로 35점이 되었다. 4K 원본은 `image-pic-high-resolution`에 둔다. 스튜디오가 카드에 그리는 이미지와 상세의 원본 다운로드는 3072 정사각 PNG다. 라이브러리 목록과 상세에 보이는 이미지는 저화질 썸네일이다. 기본 테마는 블랙 마운틴이다.

### 1-11 처음 열리는 카드

계획: 브라우저에 저장한 기준이 없어도, 여덟 규격이 정해 둔 배치로 열리게 한다. 화면 이름과 기다리는 동안의 표시를 다듬는다.

구현: 8개 프리셋의 초기화 레이아웃을 `src/shared/studio-defaults.json`에 넣었다. 저장한 기준이 없으면 처음 열 때, 프리셋을 누를 때, 초기화와 리셋 뒤에 이 배치가 나온다. 프리셋 칸에는 그 배치를 실제 비율로 줄인 이미지가 있다. 글자를 두 개 이상 고르면 `폰트 크기 함께`로 같은 비율로 커지거나 줄어든다. 메뉴 이름은 Online Studio다. 테마 원본을 불러오는 동안 오른쪽 프리뷰에 `이미지를 로딩중입니다...`가 보인다. 라이브러리 카드 테두리는 공통 선보다 연하다.

### 1-12 도형, 선, 펜

계획: 카드 크기 프리셋 아래에 기본 도형과 실선, 펜을 둔다. 도형은 크기와 radius를 조절하고, 선은 길이와 끝 모양을, 펜은 점과 곡선을 다룬다.

구현: 계산은 `src/shared/studio-shapes.ts`에 있고 프리뷰·PNG·코드 내보내기가 같은 도형을 쓴다. 도구 아래 문구는 "원, 사각형, 삼각형, 별과 선, 펜으로 카드에 형태를 그리는 도구입니다."

| 도구 | 만드는 것 | 조절 |
|---|---|---|
| 원, 사각형, 삼각형, 별 | 카드 가운데에 놓인다. 색은 카드 배경과 대비되는 흑 또는 백. | 크기 조절바는 폰트 크기 바와 같다. 도형 radius는 사각형·삼각형·별의 모서리를 0~120px로 둥글린다. 원은 radius가 없다. |
| 크기 핸들 | 도형 하나만 선택하면 변과 모서리에 동그란 점이 보인다. | Shift 없이 끌면 잡은 변만 늘어난다. Shift를 누른 채 끌면 가로와 세로가 같은 길이로 바뀐다. |
| 선 | 가운데를 지나는 가로 실선. | 두께, 양끝 핸들, 딱딱한 끝과 뭉뚝한 끝, 왼쪽·오른쪽 화살표. |
| 펜 | 점을 찍어 경로를 만든다. | 클릭은 각, 클릭한 채 끌면 대칭 곡선이다. 첫 점 근처에는 닫힘 표시가 나오고, 그때 끌면 닫히는 곡선을 조절한 뒤 채운다. Enter는 열린 경로를 마치고, Esc는 그리던 경로를 버린다. Option/Alt로 그 점을 각으로 다시 시작한다. |

도형·선·펜은 다른 레이어처럼 옮기고 복사하고 지울 수 있다. 타이틀·본문·이미지와 달리 마지막 하나도 지울 수 있다. 코드로는 카드 크기 SVG로 나간다.

### 1-13 도형의 표면

계획: 도형에 그림자, 배경과의 섞임, 위치에 따라 다른 블러, 그라데이션, 테두리를 둔다. 글자 색에도 그라데이션을 둔다.

구현:

- 그림자: 크기, 블러, 거리, 투명도. 방향은 오른쪽 아래다.
- 블렌드: 보통, 곱하기, 스크린, 오버레이, 어둡게, 밝게, 소프트 라이트, 차이. 카드 배경과 섞인다.
- 레이어 블러: 왼쪽 끝과 오른쪽 끝의 블러를 따로 두고, 그 사이로 변한다.
- 그라데이션: 도형 칠, 타이틀, 본문, 테두리에 두 색과 각도를 둔다. 끄면 단색이다.
- 테두리: 두께, 투명도, 색, 그라데이션.
- 펜으로 닫을 때도 끌면 만나는 점의 휘어짐을 조절한다.

### 1-14 점을 고르는 방식

계획: 완성된 도형과 펜 경로의 점을 다시 고친다. 한 번 누르면 크기와 radius를, 두 번 누르면 점의 위치와 휘어짐을 다룬다. 세 종류의 점이 서로 다르게 보인다.

구현:

- 선택 도구는 도형과 글자를 고른다. 펜을 켜면 그리는 상태로 바뀐다.
- 도형이나 펜 도형을 두 번 누르면 구성 점이 켜진다. 점을 한 번 누른 뒤 끌면 그 점이 이동하고, 누르자마자 끌면 휘어진다. 작은 파란색 점이 휘어짐 핸들이다. Enter로 마치고 Esc로 열기 전으로 되돌린다.
- 별은 두 번 누르지 않는다. 한 번 누르면 바깥 동그라미 다섯 개와 안쪽 마름모 다섯 개가 나온다. 바깥 점 하나를 끌면 별 전체의 크기가, 안쪽 점 하나를 끌면 골의 radius가 함께 바뀐다.
- 사각형과 삼각형은 한 번 누르면 동그란 크기 점과 함께 모서리 마름모가 나온다. 마름모 하나를 끌면 모서리 radius가 함께 바뀐다. 원은 모서리가 없어 크기 점만 나온다.
- 점 편집에 들어간 사각형·삼각형은 모서리 radius가 점에 구워지므로, radius 조절바는 숨긴다.

| 점 | 모양 | 하는 일 |
|---|---|---|
| 크기 | 동그라미 | 변·모서리, 또는 별의 바깥 점. 별은 한 점이 전체를 바꾼다. |
| radius | 마름모 | 사각형·삼각형의 모서리, 별의 안쪽 점. 한 점이 같은 radius 전체를 바꾼다. |
| 휘어짐 | 작은 파란색 점 | 두 번 눌러 연 구성 점의 곡선 핸들. |

## 통과 기준

- 네비는 Graphic Library / Online Studio / History 세 탭이다.
- 스튜디오는 Instagram Feed 1080 × 1080으로 열리고, 8개 규격과 100~4000px 직접 크기를 쓴다.
- 35개 작업물 중 하나를 테마로 쓰고, 타이틀·본문·폰트·색·radius가 프리뷰에 바로 반영된다.
- 프리뷰와 PNG는 같은 카드다. 코드 영역의 스크립트는 실행되지 않는다.
- 도형·선·펜이 프리뷰, PNG, 코드 내보내기에 같이 남는다. 한 번의 클릭으로 크기와 radius를, 두 번의 클릭으로 점의 위치와 휘어짐을 고친다.
- 서버와 LLM 키 없이 동작하고 `npm run audit`가 통과한다.

## 확인 필요

| 항목 | 현재 | 남은 결정 |
|---|---|---|
| 코드 형식 | HTML + CSS 조각으로 구현했다. | React나 JSON을 붙이는 용도면 렌더를 다시 정한다. |

| 작업 저장 | 프리셋별 초기화 기준과 추가 이미지, Saved 탭은 그 브라우저에 남는다. | 카드 초안을 여러 장 파일로 내보내 보관할지는 아직 정하지 않았다. |
| 에셋 권리 | 툴은 합성만 한다. | 아카이브 이미지를 실제 마케팅에 쓸 수 있는 범위는 사람이 판단한다. |
