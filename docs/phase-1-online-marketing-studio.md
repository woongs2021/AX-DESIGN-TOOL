# Phase 1 — Online Marketing Studio

목표: Archive에 쌓인 30개 디자인 작업물을 테마로 골라, 인스타그램·페이스북·유튜브 커버·쇼츠 같은 **온라인 마케팅 브랜드 에셋**을 만들고 PNG로 다운로드하는 툴을 만든다.

참조 결정: `D-01`, `D-03`, `D-04`, `D-11`, `D-12`, `D-14` / 기반: [Phase 0 Archive Foundation](phase-0-foundation.md)

> 상태: **구현됨** (`src/views/studio.ts`, `src/shared/studio.ts`, `src/shared/studio-presets.ts`). 코드 영역은 HTML + CSS 조각이다.

## 범위

- 입력: 빌드된 `index.json`의 캡처 30건과 각 `capture.png`. Markdown은 읽지 않는다. (`D-01`)
- 출력: 선택한 SNS 규격 크기의 PNG 파일. 브라우저에서 바로 다운로드한다.
- 서버·LLM 호출 없음. 모든 합성은 브라우저 안에서 일어난다. (`D-11`)
- 생성물은 vault, `dist/`, public 번들에 저장하지 않는다. 작업 상태는 브라우저 세션 메모리에만 둔다.

- 태블릿·데스크톱(768px 이상): 좌측 컨트롤 패널(기본 360px, 최소 240px)과 우측 프리뷰(최소 280px) 사이에 6px 분할 바가 있다. 바는 글자색 6%의 옅은 색(`--studio-divider`)이고, 마우스를 올리거나 포커스하면 primary 색으로 강조된다. 바를 드래그하면 두 영역의 너비가 바뀐다. 좌우 화살표 키로도 16px씩 조절한다. 너비는 세션 상태에 남는다. 컨트롤 패널 스크롤바는 레이아웃을 밀지 않고, 스크롤하는 동안만 잠깐 겹쳐 보인다.
- 조절바는 채워진 쪽이 primary 색이다. 빈 쪽은 다크 모드에서 흰색 40%, 라이트 모드에서 글자색 18%로 그려 두 모드 모두에서 보인다.
- 모바일(스튜디오 폭 767px 이하): 분할 바는 숨기고, 프리뷰가 위, 컨트롤 패널이 아래로 쌓인다. 프리뷰 영역 높이는 `min(64vh, 프리뷰 폭)`이다. 이 전환은 화면 폭이 아니라 디바이스 프레임 폭 기준(컨테이너 쿼리 `studio`)이라, 실제 폰과 데스크탑의 모바일 뷰가 같은 CSS로 그려진다. 상단 헤더는 화면 폭 767px 이하에서 로고·모드 버튼 한 줄과 메뉴 한 줄로 줄인다.
- 디바이스 뷰 바: 헤더 아래 한 줄 가운데에 모바일·타블렛·데스크탑 아이콘을 둔다. 아이콘 버튼에는 원형 테두리가 없고, 선택된 아이콘만 면으로 표시한다. 화면 폭 767px 이하는 모바일 하나, 768~1024px은 모바일·타블렛, 1025px 이상은 셋 다 보인다. 누르면 스튜디오 전체(컨트롤 패널 + 프리뷰)가 모바일 390px, 타블렛 820px, 데스크탑 전체 폭 프레임으로 바뀌고 그 상태로 계속 편집한다. 모바일·타블렛 프레임 좌우에는 선이 없다. 창이 좁아져 고른 모드를 못 보여 주면 한 단계 내리고, 다시 넓어지면 고른 모드로 돌아온다. 선택은 세션 메모리에만 두고 되돌리기 기록에는 넣지 않는다.
- 디바이스 뷰 바는 선 대신 면 색으로 나눈다. 두 모드 모두 분할 바와 같은 색(`--studio-divider`, 글자색 6%)이다. 스튜디오 화면에서는 헤더 아래 선을 숨긴다.
- 모바일·타블렛 프레임이 스크롤될 때 스크롤바는 컨트롤 패널처럼 콘텐츠 위에 겹쳐 스크롤하는 동안만 보이고, 폭을 차지하지 않아 콘텐츠가 움직이지 않는다.
- 프리뷰 하단 바는 프리뷰 폭 기준(컨테이너 쿼리)으로 줄바꿈한다. 760px 이하면 크기 정보와 버튼 줄을 나누고, 520px 이하면 PNG 다운로드 버튼을 폭 전체로 둔다.
- 프리뷰는 실제 출력 비율을 유지한 채 영역에 맞춰 축소해 보여 주고, 아래에 실제 픽셀 크기와 규격 이름을 표시한다. `−` / `+`로 맞춤 크기 기준 50~300%까지 확대·축소하고, 확대하면 프리뷰 안을 스크롤한다. 100%가 사방 10px 여백을 두고 영역에 맞춘 크기이고, `Fit` 버튼은 언제든 이 100%로 되돌린다. 휘어진 왼쪽 화살표는 이전 동작, 오른쪽 화살표는 그 동작을 되돌린다.

## 컨트롤 패널

컨트롤 패널은 **디자인 영역**과 **코드 영역** 두 탭으로 나눈다. 두 영역은 같은 상태 객체(`StudioState`)를 공유한다.

### 디자인 영역

마케팅 리소스를 직접 조절하는 컨트롤이다.

| 컨트롤 | 형태 | 동작 |
|---|---|---|
| 카드 크기 | 프리셋 select | SNS 기본 규격을 목록으로 제공하고, 진입 시 `Instagram Feed 1:1`을 자동 선택한다. 프리셋을 바꾸면 너비와 높이를 그 규격으로 맞춘다. |
| 카드 너비 / 높이 | range 바 + number 입력 | 각각 100~4000px. 바와 수치를 동기화하고, 범위 밖 입력은 경계값으로 맞춘다. 프리셋과 다른 크기로 직접 조절할 수 있다. |
| 너비·높이 함께 | range 바 + number 입력 | 현재 비율을 유지한 채 카드 프레임을 바꾸고, 이미지 크기·위치도 같은 비율로 함께 바꾼다. 폰트 크기와 글자 위치는 유지하고, 프리뷰에서도 글자의 화면 크기가 유지된다. 이미지는 이후 이미지 크기 바로 따로 줄일 수 있다. 한쪽이 100~4000px 한계에 닿으면 다른 쪽도 그 비율에 맞춘다. |
| 카드 타이틀 | 한 줄 텍스트 input | 시작값은 `Hello`, Montserrat 100px. 입력 즉시 프리뷰 반영. 빈 값이면 타이틀을 그리지 않는다. 프리뷰에서 드래그해 위치를 옮기고, 더블 클릭(탭)하면 그 자리에서 고친다. |
| 타이틀 컬러 | 원형 컬러 피커 + hex 입력 | 타이틀 글자색. 시작값은 카드 컬러와 대비 4.5:1을 넘는 흑 또는 백. 원 테두리는 현재 모드의 글자색을 약 30% 투명도로 그린다. |
| 타이틀 폰트 크기 | range 바 + number 입력 | 최소 5px, 최대는 카드 너비에서 좌우 10px씩 뺀 값(`너비 - 20`). 카드 너비 바로 너비를 줄이면 크기도 그 상한으로 맞춘다. 너비·높이 함께 바는 폰트 크기를 바꾸지 않는다. |
| 카드 본문 | 여러 줄 textarea | 시작값은 `헤르메스의 대표 브랜드 에셋입니다.` / `에이전트의 그래픽 결과물을 합성하였습니다.`, Pretendard 32px. 입력 즉시 프리뷰 반영. 카드 폭(좌우 10px 여백)을 넘으면 자동 줄바꿈한다. 프리뷰에서 드래그해 위치를 옮기고, 더블 클릭(탭)하면 그 자리에서 고친다. |
| 본문 컬러 | 원형 컬러 피커 + hex 입력 | 본문 글자색. 시작값은 타이틀과 같다. 원 테두리는 타이틀 피커와 같다. |
| 본문 폰트 크기 | range 바 + number 입력 | 타이틀과 같은 최소·최대. 타이틀과 따로 조절한다. |
| 타이틀 폰트 / 본문 폰트 | select 각각 | 기본 3종: Roboto, Pretendard, Montserrat. 타이틀과 본문을 다른 폰트로 고를 수 있다. `fonts/`에 `.woff2`·`.woff`·`.ttf`·`.otf`를 넣고 개발 서버를 다시 띄우거나 다시 빌드하면 두 목록에 추가된다. |
| 초기화 | 버튼 | 카드 크기, 텍스트, 폰트, 색, 이미지 위치, 코드를 처음 값으로 되돌린다. 타이틀과 본문은 기본 초안으로 돌아온다. 선택한 테마와 컨트롤 패널 너비는 유지한다. |
| 아카이브 테마 | 30개 썸네일 그리드(라디오 그룹) + 추가한 이미지 + `+` 버튼 | Graphic Library의 30개 작업물 중 하나를 고른다. 선택한 이미지 레이어에 적용하고, 선택이 없으면 맨 아래 이미지에 적용한다. 썸네일을 프리뷰로 끌어다 놓으면 놓은 자리에 카드 너비 절반 크기의 새 이미지 레이어가 맨 위로 들어간다. `+`로 고른 이미지는 이 브라우저(IndexedDB)에만 저장되어 목록 끝에 붙고, ×로 지울 수 있다. 지운 이미지를 쓰던 레이어는 테마 이미지로 바뀐다. |
| 카드 이미지 크기 | range 바 + number 입력 | 이미지 너비 100~4000px. 높이는 원본 비율을 따른다. 프리뷰에서 드래그해 위치를 옮긴다. 핀치하거나, 클릭한 뒤 상하좌우 핸들을 끌어 크기를 조절한다. |
| 카드 컬러 | 원형 컬러 피커 + hex 텍스트 입력 | `input[type=color]`와 hex 입력을 동기화한다. 카드 바탕색으로 쓴다. 피커 색면은 원형을 가득 채운다. |
| 카드 radius | range 바 + number 입력 | 둘을 동기화한다. 범위 0~120px(출력 픽셀 기준), 기본 28px. 값은 CSS 변수 `--studio-card-radius`와 캔버스 렌더에 같이 적용한다. |

### 코드 영역

사람이 코드를 붙여 넣어 카드를 구성하는 영역이다.

- 붙여 넣기 textarea에 **HTML + CSS 조각**을 넣으면 프리뷰가 그 코드로 렌더된다.
- 렌더는 `sandbox` 속성을 준 `iframe`(`srcdoc`)에서만 한다. 스크립트 실행, 외부 요청, 폼 전송을 막는다.
- 코드에서 쓸 수 있는 변수를 제공한다: `--studio-color`, `--studio-radius`, `--studio-width`, `--studio-height`, `--studio-font`, 타이틀·본문 크기와 위치, 이미지 크기와 위치, 그리고 `{{title}}`, `{{body}}`, `{{themeImage}}`, `{{image:<출처>}}`(테마가 아닌 이미지 레이어) 치환자. 디자인 영역 값이 코드 영역에 그대로 이어진다.
- `현재 디자인을 코드로 복사` 버튼으로 디자인 영역 상태를 같은 형식의 코드로 내보낸다. 미리보기 문자열과 복사 문자열은 같은 함수가 만든다.
- 코드가 비어 있으면 디자인 영역 렌더를 그대로 쓴다.

## 프리뷰와 다운로드

- 디자인 영역 렌더는 `<canvas>`에 직접 그린다: 배경 컬러 → 테마 이미지(지정한 너비, 원본 비율, 드래그한 위치) → 라운드 클리핑 → 타이틀·본문 텍스트. 화면 프리뷰와 다운로드 PNG가 같은 렌더 함수에서 나온다.
- 드래그하는 동안만 잡은 타이틀·본문·이미지 영역에 흑·백 이중 테두리를 그린다. 손을 떼면 사라지고 PNG에는 들어가지 않는다.
- 선택: 마우스로 타이틀·본문·이미지를 클릭하면 그 객체만 선택되고 파란 테두리가 보인다. Shift+클릭은 선택에 더하고, 이미 선택된 객체면 그것만 뺀다. 선택된 객체를 끌면 선택 전체가 같은 거리만큼 움직이고, 하나가 카드 가장자리에 닿으면 모두 함께 멈춰 간격이 유지된다. 한 번의 그룹 이동이 되돌리기 한 단계다. 여러 개가 선택된 상태에서 Shift 없이 클릭만 하면 그 객체만 남는다. 크기 핸들은 이미지 하나만 선택했을 때 보인다. 터치는 누른 객체 하나만 선택해 끈다.
- 단축키: 이전 동작은 Cmd+Z(맥)·Ctrl+Z(윈도우), 원래대로는 Cmd+Shift+Z·Ctrl+Y·Ctrl+Shift+Z. 한글 입력 상태에서도 키 위치(`event.code`)로 판별한다. 글자 입력칸에 커서가 있거나 스튜디오가 아닌 화면에서는 동작하지 않는다.
- 프리뷰 확대: Cmd(맥)·Ctrl(윈도우)와 +/−(숫자패드 포함)는 확대·축소 버튼과 같이 25%씩 바꾸고, 브라우저 페이지 확대는 막는다. 프리뷰 위에서 Cmd(맥)·Ctrl(윈도우)+휠을 굴리면 위는 확대, 아래는 축소다.
- 방향키 이동: 선택한 타이틀·본문·이미지를 방향키로 0.5px, Shift+방향키로 10px 옮긴다(카드 px 기준). 여러 개를 선택했으면 함께 움직이고 가장자리 규칙은 드래그와 같다. 위치는 0.5px 단위로 저장한다. 연달아 누른 이동은 손을 뗀 뒤 0.4초가 지나면 되돌리기 한 단계로 묶인다. 글자 입력칸·테마 목록 등 다른 컨트롤에 포커스가 있으면 동작하지 않는다.
- 이미지 크기: 터치 두 손가락 핀치와 트랙패드 핀치(Chromium·Firefox는 맥에서 ctrl+wheel, Safari는 gesture 이벤트)로 조절하고, 핀치 중 두 손가락을 함께 옮기면 이미지도 움직인다. 마우스로 이미지를 클릭하면 상하좌우 가장자리에 크기 핸들이 나타나고, 핸들을 끌면 반대쪽 가장자리를 고정한 채 비율을 유지하며 커지거나 줄어든다. 카드 바깥을 누르면 핸들이 사라진다.
- 텍스트 바로 수정: 타이틀·본문을 더블 클릭(터치는 더블 탭)하면 그 자리에 같은 폰트·크기·색의 편집칸이 열린다. 타이틀은 Enter, 본문은 Cmd/Ctrl+Enter 또는 바깥 클릭으로 확정하고 Esc로 취소한다. 한글 조합 중 Enter는 확정으로 처리하지 않는다. 편집 한 번이 되돌리기 한 단계다.
- 레이어: 카드 요소는 아래에서 위 순서의 레이어 목록이다. 초기 상태는 이미지(맨 아래), 본문, 타이틀(맨 위)이다. 같은 종류를 여러 개 둘 수 있고, 이미지 레이어마다 자기 이미지(아카이브 테마 또는 추가한 이미지)를 쓴다. 맨 아래 이미지가 카드의 테마다. 왼쪽 패널은 선택된 레이어(같은 종류 중 맨 위)를 고치고, 선택이 없으면 종류별 첫 레이어를 고친다. 코드 내보내기는 레이어 순서대로 마크업을 쓰고, 첫 타이틀·본문만 `{{title}}`·`{{body}}` 자리표시자로 둔다. 레이어 이전에 저장한 카드·초기화 세팅은 불러올 때 같은 세 레이어로 바뀐다.
- 객체 메뉴: 프리뷰에서 오른쪽 클릭(맥 Ctrl+클릭 포함) 또는 터치 롱프레스(0.5초, 8px 넘게 움직이면 취소)로 연다. 설정의 리셋 팝업과 같은 모양이고 누른 위치에 뜬다. 누른 객체가 선택에 없으면 그 객체만 선택한다. 항목: 복사, 붙여넣기(복사본을 새 레이어로 맨 위에 추가하고, 묶음의 왼쪽 위가 메뉴를 연 위치에 오게 놓은 뒤 선택), 맨 위로 보내기, 맨 밑으로 보내기(여러 개면 서로의 순서는 유지), 크롭하기(이미지 하나만 선택했을 때), 삭제(타이틀·본문·이미지는 종류마다 하나는 남아야 해서 마지막 하나는 지울 수 없음). 바깥 클릭·Esc로 닫고 위아래 방향키로 항목을 옮긴다. 각 동작은 되돌리기 한 단계다.
- 복사 단축키: Cmd(맥)·Ctrl(윈도우)+C는 선택한 레이어를, +V는 복사한 레이어를 붙여 넣는다. 붙여넣기 위치는 포인터가 프리뷰 위에 있으면 그 자리, 아니면 원래 위치에서 20px 옆이다. 왼쪽 패널의 버튼·선택 상자·테마 목록에 포커스가 있어도 동작한다. 글자 입력칸에 포커스가 있거나 페이지 글자를 선택해 둔 상태면 브라우저 기본 복사·붙여넣기를 쓴다. 프리뷰를 누르면 남아 있던 페이지 글자 선택은 풀린다.
- 텍스트 스타일: 타이틀·본문마다 볼드·이탤릭·밑줄 토글과 왼쪽·가운데·오른쪽 정렬 버튼이 있다. 레이어 전체에 적용되고, 선택한 레이어(없으면 종류별 첫 레이어)를 고친다. 굵기는 폰트 선택 아래 `굵기` 상자에서 Light 300 · Regular 400 · Medium 500 · SemiBold 600 · Bold 700 중에 고른다. 타이틀은 SemiBold, 본문은 Regular로 시작한다. B 버튼은 600 이상이면 켜진 상태로 보이고, 누르면 Regular와 Bold를 오간다. 내장 세 폰트는 다섯 굵기를 모두 불러온다. `fonts/`에 넣은 로컬 폰트는 파일에 든 굵기만 정확하고, 나머지는 브라우저가 가장 가까운 굵기로 그린다. 정렬은 블록 안에서 줄을 맞추고 블록의 왼쪽 위치(x)는 그대로다. Pretendard에는 이탤릭 글꼴이 없어 브라우저가 기울여 그린다. 캔버스에는 밑줄 기능이 없어 줄마다 직접 그린다. 코드 내보내기에는 `font-weight`·`font-style`·`text-decoration`·`text-align`으로 나간다. 버튼 하나가 되돌리기 한 단계다.
- 삭제 단축키: Delete(맥은 ⌫ 포함)는 선택한 레이어를 지운다. 오른쪽 클릭 메뉴의 삭제와 같고 되돌리기 한 단계다. 종류마다 마지막 하나는 지우지 않고 안내를 띄운다. 글자 입력칸에 포커스가 있으면 글자를 지운다.
- 크롭: 크롭하기를 고르면 이미지 원본 전체가 흐리게 보이고, 남길 영역에 점선 상자와 모서리·변 핸들 8개가 나타난다. 핸들로 영역을 줄이거나 늘리고(원본 밖으로는 못 나감, 최소 너비 100px), 상자 안을 끌면 영역을 옮긴다. Enter 또는 이미지 밖 클릭으로 확정, Esc로 취소한다. 원본은 지우지 않고 잘라 보이는 비율만 저장하므로 다시 크롭하기로 넓힐 수 있다.
- 핸들과 편집칸은 캔버스 위 별도 레이어라 PNG에 들어가지 않는다. 코드 영역 렌더 중에는 이 조작을 끈다.
- 이전 동작·원래대로 버튼은 슬라이더 한 번 끌기, 텍스트 입력칸에 들어갔다 나오기까지, 프리뷰 드래그 한 번, 초기화를 각각 한 단계로 기록한다. 너비·높이 함께로 바뀐 프리뷰 배율도 같이 되돌린다. 최대 40단계다.
- 프리뷰에서 드래그 히트 순서는 타이틀, 본문, 이미지다. 빈 텍스트는 잡을 수 없다. 텍스트 시작점은 카드 안에 두고, 이미지는 카드 밖으로 밀려도 약 40px은 카드 위에 남긴다.
- 다운로드 파일은 현재 카드의 실제 픽셀 크기(예: 1080 × 1080)로 만든다. 파일명은 `ax-studio-<너비>x<높이>-<theme-slug>.png`.
- YouTube Channel Cover의 안전 영역 가이드는 카드 크기가 그 프리셋(2560 × 1440)과 같을 때만 보여 주고, PNG에는 그리지 않는다.
- radius가 있으면 모서리 바깥은 투명 PNG로 둔다.
- 코드 영역 렌더 다운로드는 HTML을 SVG `foreignObject`로 감싸 캔버스에 그리는 방식으로 PNG를 만든다. 테마 이미지는 data URL로 넣어 캔버스 오염을 막는다.
- 기본 폰트는 Pretendard, Roboto, Montserrat다. 타이틀과 본문이 각각 고른다. 추가 폰트 파일은 저장소 루트 `fonts/`에 둔다. 목록은 빌드·개발 서버 시작 때 그 폴더를 읽어 붙인다. 파일을 넣은 뒤 서버를 다시 띄우거나 다시 빌드하면 셀렉트에 나타난다.

| 텍스트 입력 | 타이틀 input, 본문 textarea, 각각의 폰트 크기 바(5px~카드 너비−20). 프리뷰에서 타이틀과 본문을 드래그해 옮긴다. | 긴 본문이 카드 폭 안에서 줄바꿈된다. 빈 타이틀은 그리지 않는다. 드래그한 위치가 프리뷰와 PNG에 같다. |

| 카드 이미지 | 이미지 너비 바(100~4000px)와 프리뷰 드래그. 높이는 원본 비율을 따른다. | 크기를 바꾸면 비율이 유지된다. 드래그한 위치가 프리뷰와 PNG에 같다. |

## 통과 기준

- 네비는 Graphic Library / Online Marketing Studio / History 세 탭이다.
- 스튜디오 진입 시 Instagram Feed 1080 × 1080이 기본으로 선택되어 있고, 8개 SNS 규격으로 바꿀 수 있다. 너비와 높이는 100~4000px 범위에서 바로도 조절된다.
- 768px 이상에서 컨트롤 패널과 프리뷰 사이 바를 드래그하면 두 영역의 비율이 바뀐다.
- 30개 아카이브 작업물 중 하나를 테마로 골라 카드 비주얼에 쓸 수 있다. 이미지 너비와 위치도 조절된다.
- 타이틀·본문·폰트·폰트 크기·컬러·radius가 즉시 프리뷰에 반영된다. 타이틀과 본문은 프리뷰에서 드래그해 옮긴다.
- 프리뷰는 현재 카드의 실제 픽셀 크기 PNG로 다운로드된다.
- 코드 영역에 붙여 넣은 HTML/CSS는 sandbox 안에서만 렌더되고 스크립트는 실행되지 않는다.
- 서버, LLM 키, 외부 요청 없이 브라우저 안에서 동작하며 `npm run audit`가 통과한다.
